# Course Design Team

Use this skill when the user wants a multi-role expert team to design or improve a course.

## Workflow

1. Read `agents/course-design-team-team-lead.md` first. Treat it as the lead coordinator.
2. Read the relevant member agent files under `agents/` based on the user's request:
   - `course-planner.md` for course goals, audience, scope, and route planning.
   - `structure-designer.md` for module structure and knowledge maps.
   - `content-developer.md` for lesson content and explanations.
   - `activity-director.md` for classroom activities and interaction design.
   - `courseware-maker.md` for PPT/courseware plans.
   - `case-writer.md` for cases and scenarios.
   - `exercise-author.md` for exercises, quizzes, and assessments.
   - `project-designer.md` for project-based learning and implementation tasks.
3. Synthesize the specialist outputs into one coherent deliverable instead of exposing internal role-by-role notes unless the user asks for them.

## Output Style

Prefer practical Chinese deliverables: course positioning, learner outcomes, module outline, detailed lesson plan, PPT page plan, activity design, cases, exercises, instructor guidance, and review checklist.
